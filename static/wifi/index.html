Alendo Wi-Fi

Rede de convidados · Guest network

iPhone · iPad · Mac

  1. Instale o perfil / Install the profile:
    Alendo.mobileconfig
  2. Definições → Perfil descarregado → Instalar.
    Settings → Profile Downloaded → Install.
  3. Ligue-se a Alendo com o utilizador e a palavra-passe que recebeu.
    Join Alendo with the username and password you were given.

O perfil não contém palavras-passe e pode ser removido a qualquer momento. · The profile holds no passwords and can be removed at any time.

Android

  1. Escolha a rede Alendo. · Choose Alendo.
  2. Método EAP / EAP method: PEAP
  3. Certificado CA / CA certificate: Usar certificados do sistema · Use system certificates
  4. Domínio / Domain: osousa.com
  5. Identidade e palavra-passe que recebeu. · Identity and password you were given.

Windows · outros / others

Se aparecer um aviso de certificado, confirme que é *.osousa.com, emitido por Let's Encrypt, antes de aceitar.
If a certificate prompt appears, check it says *.osousa.com, issued by Let's Encrypt, before accepting.
